# Student Management System Using Java

## About the Project
The Student Management System is a console-based Java application designed to manage student records efficiently.

## Features
- Add new students
- View all student records
- Search students by ID
- Update student information
- Delete student records
- Validate numeric input

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Exception and input validation techniques

## Concepts Implemented
- Classes and Objects
- Constructors
- Methods
- Loops and Conditional Statements
- ArrayList
- CRUD Operations

## How to Run

### 1. Compile the program
```bash
javac StudentManagementSystem.java
```

### 2. Run the program
```bash
java StudentManagementSystem
```

## Future Improvements
- Save student records permanently using file handling
- Connect the application to a database
- Add more student details and validation
